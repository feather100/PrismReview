# 市场验证访谈提纲（阶段 1.2）

> **用途：** 验证 v1.2 报告中"空白市场"假设（第八节需求侧证据缺口：供给侧已调研，需求侧未验证）
> **目标对象：** CTO 办公室 / PMO / 咨询公司（方案评审决策链）
> **目标数量：** 5–10 人（≥5 人可出初步结论，10 人可做优先级排序）
> **形式：** 45–60 分钟半结构化访谈（线上/线下均可），访谈人 1 名 + 记录 1 名
> **版本：** v1.0（2026-08-03）

---

## 〇、访谈前准备

### 受访者筛选标准（至少满足 2 条）

- [ ] 近 12 个月内组织过或参与过 ≥2 次方案/架构/需求文档评审
- [ ] 对评审结果有决策权或强影响力（批准/否决/定级）
- [ ] 知道团队目前用什么工具/流程做评审（会议、邮件、评审系统、AI 工具）
- [ ] 体验过至少一种 AI 工具辅助文档处理（ChatGPT/Claude/Kimi/飞书 AI/Notion AI 等）

### 访谈原则（写在开场白里）

1. **不引导**：不主动提及"多 Agent 辩论""评分报告"等产品概念，先听对方现有流程；
2. **具体化**：每个问题都追问一个"上一次的真实案例"（最近一次评审是什么时候、怎么过的）；
3. **脱敏**：访谈记录匿名化，只保留岗位/行业/公司规模维度；
4. **记录**：全程录音（获同意）或双人笔记，访谈后 24h 内整理成统一模板。

## 一、开场与背景（5 分钟）

| # | 问题 | 追问 |
|---|------|------|
| 1.1 | 请简单介绍你的角色和团队（团队规模、你负责的决策类型） | 团队里谁发起评审？谁拍板？ |
| 1.2 | 过去一年你们大概评审多少份方案/架构/需求文档？ | 一份文档通常多少人参与、花多长时间？ |
| 1.3 | 评审的文档一般是哪种？（立项方案/架构设计/需求规格/招投标方案/其他） | 有没有明显的类型分布？ |

## 二、现状与流程（10 分钟）

| # | 问题 | 追问 |
|---|------|------|
| 2.1 | 描述一次最近的评审：从文档产生到结论出来，完整走了一遍什么流程？ | 有评审会吗？会前材料怎么分发？结论怎么记录？ |
| 2.2 | 评审中通常有哪些角色参与？（技术/财务/合规/PMO/业务…） | 每个角色主要关注什么？有没有意见冲突？怎么解决？ |
| 2.3 | 一次评审从开始到出结论，大概花多少**人天**？ | 有没有算过机会成本？（被评审项目等待的时间） |
| 2.4 | 评审结论目前以什么形式留存？（会议纪要/邮件/评分表/评审系统/口头） | 过后能回溯"当时为什么批/不批"吗？ |

## 三、痛点（10 分钟）

| # | 问题 | 追问 |
|---|------|------|
| 3.1 | 当前评审流程里，你觉得最痛的三件事是什么？ | 排最前面的那个痛，影响有多大？（量化：多花几天/漏掉问题/返工） |
| 3.2 | 有没有发生过"评审没发现的严重问题，上线/落地后才暴露"的案例？ | 当时评审为什么没发现？（人不够/时间紧/只看了一部分） |
| 3.3 | 评审结论是否经常不一致？（不同评审人意见冲突/标准不一/凭感觉） | 有没有人提出过"应该有个统一的评分标准"？ |
| 3.4 | 如果评审可以更快，你最想省掉的是哪一段？（会前阅读/会上讨论/会后整理） | 为什么是这一段？ |

## 四、对 AI 评审的态度与信任（10 分钟）

| # | 问题 | 追问 |
|---|------|------|
| 4.1 | 你（或团队）现在用 AI 处理过文档评审相关的事吗？具体做什么？ | 用得最多的是哪种？（总结/问答/找问题/打分） |
| 4.2 | 如果用 AI 帮你初筛一份方案文档，你最担心什么？ | 漏报（该发现没发现）/误报（鸡毛蒜皮当大事）/不可解释（不知道为什么这么说）？哪个最致命？ |
| 4.3 | 什么样的 AI 评审输出会让你愿意认真看？（结构/分数/依据/置信度/谁提的） | 一条"带依据引用原文的批评" vs 一条"泛泛而谈的批评"，你会区别对待吗？ |
| 4.4 | 如果 AI 给出一个评分（如 10 分制 6.5 分），你要在什么条件下才敢用它辅助决策？ | 需要它解释打分依据吗？需要和人工评审对照过才信吗？ |
| 4.5 | 你更信任"一个 AI 通盘给结论"，还是"多个 AI 扮演不同角色辩论后收敛"？为什么？ | 如果后者，你担心辩论是"形式主义"吗？ |

## 五、付费意愿与功能优先级（10 分钟）

### 5.1 场景化 WTP 测试（关键题，逐档问）

> 假设有一个工具：把你的方案文档传进去，**2 小时后**返回一份结构化评审报告——包含多个视角（技术/财务/合规/执行）、每条意见带原文依据、附一个多维评分和风险清单。

- **A 快速档**（1 页摘要 + 风险标记，免费/极低价）：你会用吗？每月愿意付多少？（<50 元 / 50–100 / 不考虑）
- **B 标准档**（完整评分报告 + 改进建议，¥X/次）：如果 ¥199/次，你个人/团队会买吗？¥499 呢？
- **C 深度档**（正式评审报告 + 审计溯源 + 人工复核，按项目计价 ¥X,XXX）：如果一次 ¥3,000–5,000（替代一场 2 天评审会），你们会为**什么类型**的项目付费？每年几次？

**追问：**
- 定价锚点测试：你会拿它和什么比？（外包咨询 ¥X 万 / 一场评审会 ¥X / ChatGPT 会员 ¥X）
- 如果"AI 评分可信度已用 100 份真实方案与人工评审对照过（相关性 0.8）"，你会不会更愿意付费？这个证据值多少钱？

### 5.2 功能优先级排序

> 以下功能如果只能选 3 个，你选哪 3 个？（打乱顺序呈现）

- 多角色辩论式评审（技术/财务/合规多视角）
- 带原文依据的逐条意见（可点击跳转原文）
- 多维加权评分 + 置信度
- 与公司流程集成（钉钉/飞书/Confluence/邮件）
- 评审历史与审计追踪（谁改了什么、为什么）
- 评审模板自定义（按公司标准定制维度与权重）
- 与人工评审对照/校准（AI 分 vs 人工分）

### 5.3 替代方案

| # | 问题 | 追问 |
|---|------|------|
| 5.3.1 | 如果不买这个工具，你们现在/未来会用什么替代？ | ChatGPT + Prompt？外包？内部评审会？ |
| 5.3.2 | 什么情况下你会**立刻**改用竞品/替代方案？ | 价格/质量/集成度，哪个先触发？ |

## 六、收尾（5 分钟）

| # | 问题 | 追问 |
|---|------|------|
| 6.1 | 如果这个产品下周就能用，你最想先拿哪一份文档试？ | 为什么是它？ |
| 6.2 | 还有谁（同事/同行）对这类工具最有发言权？能帮忙引荐吗？ | 记录推荐人清单 |
| 6.3 | 有没有我们没想到的评审场景/需求？ | 开放式收尾 |

## 八、分析与决策标准（访谈全部完成后）

| 验证目标 | 判定信号 | 行动 |
|---------|---------|------|
| 痛点存在 | ≥60% 受访者给出 ≥2 个具体痛点案例 | 进入阶段 3 楔子场景细化 |
| 付费意愿 | ≥40% 对标准档给出明确"会买"或"试用"意向 | 定价假设成立，做价格测试页 |
| 评分可信度是门槛 | ≥50% 把"不可信"列为前两大担心 | 把《评分可信度验证方案》提到 P0 最前 |
| 替代方案威胁 | ≥50% 认为"ChatGPT + Prompt 够用" | 调整差异化话术：强调多轮/审计/一致性 |
| 辩论形式被质疑 | ≥40% 认为多角色辩论是"形式主义" | 产品演示重点展示"辩论如何改变结论"的真实案例 |

**最低交付：** ≥5 场有效访谈 + 一份《市场验证报告》（痛点排序 / 付费意愿 / 功能 Top3 / 替代方案 / 对"空白市场"假设的最终判断）。
